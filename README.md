# go-tinygo-errors

Error code mappings for my BNO08X implementation (and related peripherals) for TinyGo, built on [`tinygo-errors`](https://github.com/ralvarezdev/tinygo-errors).

**Note:** This repository is archived and read-only. The original README was titled `go-bno08x-errors`, but the module is `github.com/ralvarezdev/go-tinygo-errors`.

## Features

- **Error code ranges** — start numbers per component in `constants.go`: buffers, BNO08X, pull-up resistor, ESC motor, servo and others.
